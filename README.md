# Mini Bazar — متجر إلكتروني

متجر إلكتروني لعرض المنتجات وإدارة تجربة الشراء، مبني على React وTypeScript وVite مع مكونات Firebase وإعدادات نشر Hostinger.

## التشغيل والتطوير

`npm run dev` للتطوير و`npm run build` للبناء. راجع `FIREBASE_SETUP.md` و`HOSTINGER_DEPLOYMENT.md`.

## ملاحظات
